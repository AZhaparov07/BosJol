# BosJol — Smart Bus Occupancy & Route Analytics

**BosJol** (*Бос Жол* / *Bus + Jol*) — интеллектуальная система мониторинга загруженности автобусов в реальном времени и умного подбора маршрутов (гибрид 2GIS и ONAY).
Название объединяет казахские слова **«Бос»** (свободный), **«Жол»** (дорога/путь) и английское **«Bus»** (автобус) — *свободная дорога и свободный автобус*.

## Архитектура проекта
- **`cv/`** — Computer Vision (OpenCV + YOLO + ByteTrack): подсчет входящих (`+1`) и выходящих (`-1`) пассажиров с камер над дверьми автобуса.
- **`database/`** — SQL-схемы и аналитические запросы (маршруты, остановки, автобусы, история посадок).
- **`backend/`** — FastAPI сервер: прием событий с автобусов, расчет текущей заполненности и подбор оптимальных маршрутов от точки А до точки Б.
- **`ml/`** — Machine Learning: прогнозирование количества входящих пассажиров и загруженности автобусов по остановкам и времени суток.
- **`frontend/`** — Клиентское приложение (гибрид 2GIS и ONAY): карта автобусов, цветовая индикация заполненности салона и сравнение подходящих автобусов по времени прибытия и загруженности.
